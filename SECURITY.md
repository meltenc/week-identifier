# Security Policy

## Supported versions

Only the latest release of `week-identifier` receives fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through [GitHub's private vulnerability reporting](https://github.com/meltenc/week-identifier/security/advisories/new).

You can expect a first answer within a week. Once a fix is released, the advisory will be published with credit to the reporter (unless you prefer otherwise).
